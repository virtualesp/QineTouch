# 🎨 Windows UI (配置面板)

这是 **QInE Touch Mapper** 的可视化配置工具。它启动一个本地 Web 服务器，允许用户通过浏览器直观地调整按键映射、灵敏度及其他高级参数。

## ✨ 功能特性

*   **🌐 本地 Web 服务**：轻量级 HTTP 服务器，无额外依赖。
*   **💾 实时保存**：前端修改配置后，直接写入 `windows_sender/config.json`，发射端即刻生效。
*   **📱 设备状态监控**：实时读取并发显示硬件连接状态（MAC地址、激活状态、固件版本）。
*   **📐 可视化编辑**：(前端功能) 支持拖拽按键、调整轮盘大小、设置分辨率参考。

## 🚀 启动方式

直接运行程序即可。控制台会输出访问地址：

```
启动UI服务器: http://localhost:61701
```

如果端口被占用，程序会自动尝试 `61702` 等后续端口。

## 📂 文件交互

UI 端并不直接与串口通信，而是通过文件系统与 **Sender** 进行交互：

1.  **读写配置**：操作 `../windows_sender/config.json`。
2.  **读取状态**：轮询 `../windows_sender/device_status.json` 获取设备信息。

## 🛠️ 技术栈

*   **后端**：Go `net/http` 标准库。
*   **前端**：HTML/JS/CSS (位于 `static/` 目录)。
