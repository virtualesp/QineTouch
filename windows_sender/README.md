# 🎮 Windows Sender (核心发射端)

这是 **QInE Touch Mapper** 的核心引擎部分。它负责监听 Windows 系统的键盘与鼠标输入，将其转换为触控信号，并通过串口（Serial Port）发送给外部设备（如 Android 手机或 HID 硬件）。

## ✨ 功能特性

*   **🛡️ 全局输入捕获**：使用 Windows API 底层钩子，支持独占鼠标输入。
*   **🖱️ 智能映射系统**：
    *   **FPS 模式**：无限鼠标滑动，模拟射击游戏视角。
    *   **MOBA 模式**：支持鼠标点击映射。
    *   **WASD 轮盘**：将键盘移动转换为虚拟摇杆操作，内置物理平滑算法。
*   **🔌 串口通讯**：高性能串口写入（默认波特率 921600），支持热插拔检测。
*   **👻 防检测机制**：开源版本已移除。
    *   **随机偏移**：点击坐标加入微小随机抖动。
    *   **微动模拟**：长按时模拟手指的生理性微颤。
*   **🖼️ 透明遮罩层**：提供一个透明置顶窗口，防止鼠标误触 Windows 桌面图标。

## 🚀 快速开始

1.  **管理员运行**：建议以 **管理员身份** 运行程序。
2.  **自动连接**：程序启动时会根据配置文件链接串口。
3.  **配置文件**：自动读取 `config.json`，支持热重载（修改文件后立即生效）。

## ⌨️ 快捷键

| 按键组合 | 功能描述 |
| :--- | :--- |
| **F8** | 🖥️ 切换遮罩层显示/隐藏（窗口模式 vs 全屏模式） |
| **ALT** (默认) | 🔄 切换 **鼠标模式** / **FPS 映射模式** |
| **Ctrl + F9** | 🛠️ 运行边界诊断测试（需在开发者选项打开指针位置） |

## ⚙️ 核心逻辑

*   **输入监听**：`windows_sender/main.go` 中的 `wndProc` 和 `mouseHookProc` 处理底层消息。
*   **坐标转换**：将屏幕像素坐标归一化为 `0.0 - 1.0` 的相对坐标，适配不同分辨率。
*   **状态同步**：通过 `device_status.json` 与 UI 端共享设备连接状态。

## 📦 依赖

*   `golang.org/x/sys/windows`: 调用 Win32 API。
*   `go.bug.st/serial`: 跨平台串口通讯。
